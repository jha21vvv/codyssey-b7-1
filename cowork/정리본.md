## 1. `app/core/config.py` — Pydantic 전역 환경설정 및 싱글톤

### 💻 핵심 코드 추출 & 1·2차 듀얼 주석
```python
# [1차 주석] Pydantic Settings 라이브러리에서 기본 설정 클래스와 옵션 설정 도구를 가져옵니다.
# [2차 주석] 
#   - 비유: 이 도구는 '스마트폰의 환경설정 앱' 같은 것입니다.
#   - 상세: 파이썬 기본 os.environ은 문자열만 읽고 오타가 나도 안 알려주지만, 
#     Pydantic의 BaseSettings는 .env 파일에서 값을 찾아 타입(숫자, 불리언 등)까지 자동으로 맞춰 검사해 줍니다.
from pydantic_settings import BaseSettings, SettingsConfigDict


# [1차 주석] 프로젝트 전역 설정을 정의하는 Settings 클래스를 선언합니다.
# [2차 주석] 
#   - 비유: '회사 신입사원 서약서 양식(틀)'입니다.
#   - 상세: 우리 서비스 전체가 필요로 하는 모든 비밀키, DB 주소, 포트 번호 등의 이름과 기본값을 규격화해 둡니다.
class Settings(BaseSettings):

    # [1차 주석] 프로젝트의 공식 이름을 문자열 형태로 정의합니다. (기본값 제공)
    # [2차 주석] 웹 브라우저 Swagger API 문서 상단이나 서버 시작 로그에 멋지게 찍힐 서비스 간판 이름입니다.
    PROJECT_NAME: str = "Codyssey B7-1 AI Chatbot"

    # [1차 주석] 디버그 모드 활성화 여부를 불리언(True/False) 값으로 지정합니다.
    # [2차 주석] 개발 중에는 True로 두어 에러 발생 시 상세한 에러 화면을 보고, 실서버 배포 시 False로 바꿔 해커에게 정보 노출을 막습니다.
    DEBUG: bool = True

    # [1차 주석] 사용할 데이터베이스 연결 주소(URL)를 지정합니다.
    # [2차 주석] 
    #   - 비유: "우리 가게 장부 파일이 어디 사물함에 있는지" 적어둔 위치 표지판입니다.
    #   - 상세: 'sqlite:///./chat_service.db'는 현재 폴더에 있는 chat_service.db라는 파일 하나를 통째로 DB로 쓰겠다는 뜻입니다.
    DATABASE_URL: str = "sqlite:///./chat_service.db"

    # [1차 주석] JWT 토큰을 암호화하고 도장을 찍을 때 사용하는 서버 비밀키입니다.
    # [2차 주석] 
    #   - 비유: 사장님만 가지고 있는 '특수 인감도장'입니다.
    #   - 상세: 이 키가 유출되면 해커가 마음대로 가짜 로그인 토큰을 위조할 수 있으므로, 실제 배포 시에는 .env에서 복잡한 비밀키로 덮어씁니다.
    SECRET_KEY: str = "temporary-secret-key-for-development-change-in-production"

    # [1차 주석] JWT 도장을 찍을 때 사용할 암호화 알고리즘 방식입니다.
    # [2차 주석] 전 세계 웹 표준으로 가장 널리 쓰이는 해시 알고리즘인 'HS256'을 사용합니다.
    ALGORITHM: str = "HS256"

    # [1차 주석] 로그인 유지 시간(토큰 유효기간)을 분 단위 정수로 설정합니다.
    # [2차 주석] 60 * 24 = 1440분(딱 24시간) 동안 로그인 상태가 유지되도록 계산해 둔 것입니다.
    ACCESS_TOKEN_EXPIRE_MINUTES: int = 60 * 24

    # [1차 주석] OpenAI 등 외부 AI 서비스를 호출할 때 필요한 API 인증 키입니다.
    # [2차 주석] 
    #   - 비유: 유료 고속도로를 지날 때 내는 '하이패스 카드'입니다.
    #   - 상세: 깃허브에 키가 올라가면 돈이 털릴 수 있으므로 코드에는 빈칸("")으로 두고, 로컬의 .env 파일에만 몰래 적어둡니다.
    AI_API_KEY: str = ""

    # [1차 주석] AI API의 서버 엔드포인트 기본 주소입니다.
    # [2차 주석] 코디세이 평가용 프록시 콘솔이나 모의(Mock) AI 주소로 우회해야 할 때 이 값을 .env에서 바꿔치기합니다.
    AI_BASE_URL: str = ""

    # [1차 주석] 챗봇이 기본으로 사용할 OpenAI 모델의 명칭입니다.
    # [2차 주석] 가성비와 속도가 가장 뛰어난 'gpt-4o-mini'를 기본 모델로 채택했습니다.
    AI_MODEL_NAME: str = "gpt-4o-mini"

    # [1차 주석] AI 응답을 기다릴 최대 제한 시간(초)을 실수(float)로 지정합니다.
    # [2차 주석] 
    #   - 비유: "10초 안에 답변 안 오면 주문 취소하고 손님한테 죄송하다고 알리기"입니다.
    #   - 상세: OpenAI 서버가 먹통이 되었을 때 우리 서버 전체가 무한정 멈춰있는 현상을 방지합니다.
    AI_TIMEOUT_SECONDS: float = 10.0

    # [1차 주석] 전체 대화 로그 조회를 위한 최고 관리자 전용 인증 키입니다.
    # [2차 주석] 권태현 팀원의 로그 조회 API(`GET /api/logs/admin`)에서 일반 손님이 남의 대화를 못 훔쳐보게 잠그는 마스터키입니다.
    ADMIN_API_KEY: str = ""

    # [1차 주석] Pydantic에게 .env 파일을 어떻게 읽을지 지시하는 설정 딕셔너리입니다.
    # [2차 주석]
    #   - env_file=".env": 현재 폴더의 .env 텍스트 파일을 찾아 열어라.
    #   - env_file_encoding="utf-8": 한글이 적혀 있어도 글자가 깨지지 않게 읽어라.
    #   - extra="ignore": 혹시 .env에 우리가 적지 않은 엉뚱한 변수가 더 있어도, 툴툴대지 말고 그냥 무시해라.
    model_config = SettingsConfigDict(
        env_file=".env",
        env_file_encoding="utf-8",
        extra="ignore"
    )


# [1차 주석] Settings 클래스를 실체화(인스턴스 생성)하여 전역 변수 'settings'에 담아둡니다.
# [2차 주석] 
#   - 🚨 핵심 개념 (싱글톤 패턴):
#   - 비유: 회사에 '총무팀장'을 10명 뽑지 않고 딱 1명만 임명해 둔 것입니다.
#   - 상세: 서버가 켜질 때 이 코드가 실행되어 .env를 딱 한 번만 읽고 메모리에 올려둡니다. 
#     이후 로그인 모듈, AI 모듈 등 다른 모든 파일은 이미 만들어진 이 '단 1개의 settings'를 공유하므로 
#     디스크 파일을 계속 읽느라 컴퓨터가 버벅대는 일이 완전히 사라집니다!
settings = Settings()
```

## 2. `app/core/database.py` — SQLite 커넥션 및 DB 세션 생명주기

### 💻 핵심 코드 추출 & 1·2차 듀얼 주석
```python
# [1차 주석] SQLAlchemy 라이브러리에서 DB 엔진을 생성하는 함수를 가져옵니다.
# [2차 주석] DB 파일과 우리 파이썬 코드 사이에 실제 파이프라인(물길)을 뚫어주는 핵심 도구입니다.
from sqlalchemy import create_engine

# [1차 주석] ORM 모델을 만들 기초 클래스(declarative_base), 세션 공장(sessionmaker), 세션 타입(Session)을 가져옵니다.
# [2차 주석] 
#   - declarative_base: 신재은(User), 권태현(ChatLog) 팀원이 파이썬 클래스로 DB 표(테이블)를 만들 수 있게 해주는 마법의 도화지입니다.
#   - sessionmaker: DB와 통화할 때마다 통화 연결 통로(세션)를 찍어내 주는 기계입니다.
from sqlalchemy.orm import declarative_base, sessionmaker, Session

# [1차 주석] yield 키워드를 사용하는 함수(제너레이터)의 파이썬 타입 힌트를 가져옵니다.
# [2차 주석] "이 함수는 값을 한 번 주고 끝나는 게 아니라, 잠깐 빌려줬다가 나중에 돌아오는 함수다"라고 컴퓨터에게 알려주는 라벨입니다.
from typing import Generator

# [1차 주석] 앞서 config.py에서 싱글톤으로 만들어둔 설정 객체를 가져옵니다.
# [2차 주석] 하드코딩 대신 settings.DATABASE_URL을 꺼내 쓰기 위함입니다.
from app.core.config import settings


# [1차 주석] 데이터베이스 연결 엔진을 생성합니다. (SQLite 전용 멀티스레드 옵션 적용)
# [2차 주석] 
#   - 🚨 핵심 개념 (check_same_thread: False):
#   - 비유: 주방 일꾼(스레드)이 여러 명인데, 식당 금고지기(SQLite)가 "처음 문 연 1번 직원만 돈 꺼내!"라고 고집부리는 것을 막는 것입니다.
#   - 상세: FastAPI는 손님이 몰리면 여러 스레드가 동시에 번갈아가며 일합니다. SQLite의 기본 깐깐한 검사를 끄지 않으면(False로 안 바꾸면) 
#     "다른 스레드가 건드렸다!"면서 서버가 즉시 폭발(다운)하므로, SQLite를 웹 서버에서 쓸 때 반드시 넣어야 하는 필수 마법의 옵션입니다.
engine = create_engine(
    settings.DATABASE_URL,
    connect_args={"check_same_thread": False}
)

# [1차 주석] 데이터베이스와 대화할 세션(Session)을 찍어내는 세션 공장을 만듭니다.
# [2차 주석] 
#   - autocommit=False: 우리가 "저장해!(commit)"라고 확실히 도장 찍기 전까지는 DB에 멋대로 저장하지 말라는 안전장치입니다.
#   - autoflush=False: 우리가 요청하기 전에 버퍼를 멋대로 비우지 말라는 옵션입니다.
SessionLocal = sessionmaker(autocommit=False, autoflush=False, bind=engine)

# [1차 주석] 모든 데이터베이스 테이블 모델들이 상속받을 기본 Base 클래스를 만듭니다.
# [2차 주석] 신재은 팀원의 User 테이블, 권태현 팀원의 ChatLog 테이블이 이 Base를 상속받아야 나중에 서버 시작할 때 DB에 표가 자동으로 그려집니다.
Base = declarative_base()


# [1차 주석] API 요청이 올 때마다 DB 세션을 빌려주고 작업이 끝나면 안전하게 닫아주는 의존성 주입(DI) 함수입니다.
# [2차 주석]
#   - 🚨 핵심 개념 (커넥션 누수 방지 & yield):
#   - 비유: 도서관 책(DB 세션) 대여 시스템입니다.
#   - 상세 동작 과정:
#     1) db = SessionLocal(): DB와 이야기할 전화 통화 연결을 켭니다.
#     2) yield db: API 처리 함수(회원가입, 대화 저장 등)에게 "자, 전화기 줄 테니 일 봐!" 하고 잠깐 넘겨줍니다.
#     3) finally: db.close(): 손님의 API 처리가 성공했든, 중간에 치명적 에러가 터졌든 간에 무조건 100% 실행되어 전화를 탁 끊어줍니다.
#   - 효과: 전화를 안 끊고 도망가서 통화 회선이 바닥나는 '커넥션 풀 고갈(Connection Leak)'을 원천 차단합니다!
def get_db() -> Generator[Session, None, None]:
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

## 3. `app/core/logger.py` — 표준 로깅 및 Request-ID 추적 미들웨어

### 💻 핵심 코드 추출 & 1·2차 듀얼 주석
```python
# [1차 주석] 파이썬 내장 로깅 모듈을 가져옵니다.
# [2차 주석] print() 대신 날짜, 시간, 에러 수준이 예쁘게 찍히는 전문 기록 장치입니다.
import logging

# [1차 주석] 파이썬 표준 시스템 모듈(표준 출력 stdout 등)을 가져옵니다.
# [2차 주석] 터미널 콘솔 화면에 로그 글자를 실시간으로 뿜어내기 위해 필요합니다.
import sys

# [1차 주석] 전 세계에서 겹치지 않는 고유 식별자(UUID)를 생성하는 모듈을 가져옵니다.
# [2차 주석] 수많은 손님의 요청이 동시에 뒤섞일 때, 손님 이마에 붙일 '고유 번호표'를 만들기 위함입니다.
import uuid

# [1차 주석] 시간을 측정하기 위한 파이썬 내장 시간 모듈을 가져옵니다.
# [2차 주석] API 요청이 들어온 순간부터 응답을 보낼 때까지 몇 밀리초(ms)가 걸렸는지 스톱워치를 재기 위해 씁니다.
import time

# [1차 주석] FastAPI의 HTTP 요청 객체 타입을 가져옵니다.
# [2차 주석] 손님이 보낸 URL, 메소드(GET/POST), 헤더 정보가 담겨 있는 '손님의 주문서' 봉투입니다.
from fastapi import Request

# [1차 주석] Starlette 프레임워크의 기초 미들웨어 클래스를 가져옵니다.
# [2차 주석] 모든 요청과 응답의 길목을 지키는 '고속도로 톨게이트' 같은 부품을 만들기 위한 뼈대입니다.
from starlette.middleware.base import BaseHTTPMiddleware

# [1차 주석] 클라이언트에게 돌려줄 HTTP 응답 객체 타입을 가져옵니다.
# [2차 주석] 손님에게 줄 '음식과 영수증' 객체입니다.
from starlette.responses import Response


# [1차 주석] 'codyssey_logger'라는 고유 이름을 가진 시스템 로거를 생성합니다.
# [2차 주석] 우리 프로젝트 전용 방송국을 하나 개국한 것과 같습니다.
logger = logging.getLogger("codyssey_logger")

# [1차 주석] 로거의 최소 기록 등급을 INFO(정보성 로그) 이상으로 설정합니다.
# [2차 주석] 너무 자질구레한 디버그(DEBUG) 내용은 거르고, 중요한 정보(INFO), 경고(WARNING), 에러(ERROR)만 기록하겠다는 뜻입니다.
logger.setLevel(logging.INFO)

# [1차 주석] 이미 등록된 핸들러(출력 통로)가 없을 때만 새로운 핸들러들을 등록합니다.
# [2차 주석] 서버가 재시작되거나 모듈이 다시 로드될 때 똑같은 로그가 2줄, 3줄씩 중복해서 찍히는 버그를 막아주는 똑똑한 조건문입니다.
if not logger.handlers:

    # [1차 주석] 로그 출력 형식을 지정하는 포맷터를 정의합니다. (날짜시각 | 로그레벨 | 메시지)
    # [2차 주석] 2026-10-29 18:00:00 | INFO    | [요청 수신] 형태로 모든 로그가 줄맞춰 깔끔하게 나오도록 규격을 통일합니다.
    formatter = logging.Formatter(fmt="%(asctime)s | %(levelname)-7s | %(message)s")
    
    # [1차 주석] 터미널 콘솔 화면에 실시간으로 로그를 출력하는 콘솔 핸들러를 붙입니다.
    # [2차 주석] 개발자가 VS Code 터미널 창을 보면서 서버가 잘 돌아가는지 눈으로 즉시 확인하는 모니터 통로입니다.
    console_handler = logging.StreamHandler(sys.stdout)
    console_handler.setFormatter(formatter)
    logger.addHandler(console_handler)

    # [1차 주석] 로그 내용을 'server.log' 파일에 영구 기록하는 파일 핸들러를 붙입니다.
    # [2차 주석] 
    #   - 비유: 비행기의 '블랙박스'입니다.
    #   - 상세: 서버 컴퓨터가 꺼지거나 오류로 튕겨도 나중에 무슨 일이 있었는지 증거를 열어볼 수 있도록 하드디스크에 UTF-8로 저장합니다.
    file_handler = logging.FileHandler("server.log", encoding="utf-8")
    file_handler.setFormatter(formatter)
    logger.addHandler(file_handler)


# [1차 주석] 모든 HTTP 요청을 가로채서 로깅하고 시간을 재는 커스텀 로깅 미들웨어 클래스를 정의합니다.
# [2차 주석] 식당 입구에 서서 손님이 들어올 때 시계를 누르고, 나갈 때 맛있게 드셨는지 영수증을 확인하는 '지배인' 클래스입니다.
class LoggingMiddleware(BaseHTTPMiddleware):

    # [1차 주석] 실제 요청이 지나갈 때마다 자동으로 실행되는 핵심 디스패치 함수입니다.
    # [2차 주석] request(들어온 주문서)와 call_next(주방으로 주문서를 넘기는 동작)를 인자로 받아 처리합니다.
    async def dispatch(self, request: Request, call_next):

        # [1차 주석] 전 세계에서 유일한 8자리 고유 Request-ID를 발급합니다.
        # [2차 주석] 
        #   - 비유: 은행 창구의 '주문 대기표 번호(예: a1b2c3d4)'입니다.
        #   - 상세: 동시 손님이 100명 몰려도 이 번호표만 추적하면 "아, a1b2c3d4 손님이 몇 초에 들어와서 몇 초에 응답받았구나"를 1:1로 정확히 파악할 수 있습니다.
        req_id = str(uuid.uuid4())[:8]

        # [1차 주석] 발급한 Request-ID를 요청 객체의 상태 공간(state)에 보관해 둡니다.
        # [2차 주석] 뒤이어 일할 조명환 팀원의 AI 호출 코드나 권태현 팀원의 로그 코드에서도 이 번호표를 꺼내 쓸 수 있도록 공유 주머니에 넣어둔 것입니다.
        request.state.req_id = req_id

        # [1차 주석] 스톱워치를 켭니다. (요청 수신 시점 시각 기록)
        # [2차 주석] 처리가 끝난 뒤 소요 시간(지연 시간, Latency)을 정밀하게 계산하기 위한 시작점입니다.
        start_time = time.time()
        
        # [1차 주석] Cloudflare나 프록시 헤더에서 실제 외부 사용자의 공인 IP를 꺼냅니다.
        # [2차 주석] 
        #   - 비유: 퀵서비스 배달원이 물건을 대신 전해줄 때, '원래 보낸 사람의 진짜 집 주소'를 메모지에서 확인하는 작업입니다.
        forwarded_for = request.headers.get("x-forwarded-for")
        real_ip = request.headers.get("x-real-ip")
        if forwarded_for:
            # 여러 프록시를 거친 경우 콤마로 나열되므로, 가장 첫 번째 주소(진짜 원본 사용자 IP)를 뗍니다.
            client_host = forwarded_for.split(",")[0].strip()
        elif real_ip:
            client_host = real_ip.strip()
        elif request.client:
            # 프록시가 없는 일반 로컬 환경이면 접속자 IP를 직접 가져옵니다.
            client_host = request.client.host
        else:
            client_host = "unknown"

        # [1차 주석] 🚨 과제 필수 요구조건: [요청 수신] 로그를 표준 형식으로 출력합니다.
        # [2차 주석] 예: "[a1b2c3d4] [요청 수신] POST /api/chat (from 123.45.67.89)" 형태로 누가 무슨 요청을 했는지 명확히 남깁니다.
        logger.info(f"[{req_id}] [요청 수신] {request.method} {request.url.path} (from {client_host})")
        
        try:
            # [1차 주석] 요청을 실제 담당 API 라우터(로그인, 채팅, 로그 등)에게 넘겨주고 결과를 기다립니다.
            # [2차 주석] 주방장에게 주문서를 넣고 음식이 완성되어 나올 때까지 대기(await)하는 순간입니다.
            response: Response = await call_next(request)

            # [1차 주석] 스톱워치를 멈추고 처리 시간을 밀리초(ms) 단위로 계산하여 소수점 둘째 자리까지 반올림합니다.
            # [2차 주석] (끝난 시각 - 시작 시각) * 1000 = 23.45ms 처럼 사람이 보기 쉬운 밀리초 단위로 변환합니다.
            duration_ms = round((time.time() - start_time) * 1000, 2)
            
            # [1차 주석] 응답 헤더('X-Request-ID')에 아까 만든 8자리 번호표를 꽂아 손님에게 돌려줍니다.
            # [2차 주석] 손님(웹 프론트엔드)이 "어? 왜 에러 나지?" 하고 문의할 때, 브라우저 개발자 도구에서 이 번호표만 불러주면 서버 로그를 1초 만에 찾을 수 있습니다.
            response.headers["X-Request-ID"] = req_id
            
            # [1차 주석] 🚨 처리 완료 상태 코드와 소요 시간을 로그에 기록하고 응답을 반환합니다.
            # [2차 주석] 예: "[a1b2c3d4] [응답 완료] POST /api/chat -> status=200 (150.23ms)"
            logger.info(f"[{req_id}] [응답 완료] {request.method} {request.url.path} -> status={response.status_code} ({duration_ms}ms)")
            return response

        except Exception as exc:
            # [1차 주석] 주방에서 요리하다 치명적인 예외(에러)가 터졌을 때 실행되는 안전망입니다.
            # [2차 주석] 몇 ms 만에 에러가 터졌는지, 에러 메시지(exc)는 무엇인지 빨간색 에러 로그로 확실히 남기고 예외를 다시 던집니다.
            duration_ms = round((time.time() - start_time) * 1000, 2)
            logger.error(f"[{req_id}] [서버 예외 발생] {request.method} {request.url.path} ({duration_ms}ms) - {str(exc)}")
            raise exc
```

## 4. `app/main.py` — FastAPI 메인 허브, 수명주기(Lifespan) 및 라우터 오케스트레이션

### 💻 핵심 코드 추출 & 1·2차 듀얼 주석
```python
# [1차 주석] FastAPI 웹 프레임워크와 HTTP 요청 객체를 가져옵니다.
# [2차 주석] 웹 서버의 심장을 만드는 핵심 모듈입니다.
from fastapi import FastAPI, Request

# [1차 주석] 다른 도메인(웹사이트)에서의 API 호출을 허용해 주는 CORS 미들웨어를 가져옵니다.

from fastapi.middleware.cors import CORSMiddleware

# [1차 주석] 안재현이 만든 전역 설정 객체(settings)를 가져옵니다.

from app.core.logger import logger, LoggingMiddleware


# [1차 주석] 🚨 최신 FastAPI 표준: 서버의 시작과 종료 생애주기(Lifespan)를 관리하는 함수입니다.
# [2차 주석] 
#   - 비유: 식당 오픈 준비와 마감 청소 총괄 매니저입니다.
@asynccontextmanager
async def lifespan(app: FastAPI):
    # --- [1단계: 서버 켜질 때 딱 1번 실행되는 오픈 준비] ---
    logger.info(f"[{settings.PROJECT_NAME}] 애플리케이션 시작 중... DB 테이블 점검")

    # [1차 주석] Base를 상속받은 모든 모델(User, ChatLog 등)의 DB 테이블을 실제 데이터베이스에 자동 생성합니다.
    # [2차 주석] 
    #   - 비유: 장사 시작하기 전에 '장부 표 양식'을 공책에 미리 줄 그어놓는 작업입니다.
    #   - 상세: 평가자나 개발자가 SQL CREATE TABLE 명령어를 수동으로 입력할 필요 없이, 서버만 켜면 자동으로 DB 파일에 표가 싹 만들어집니다!
    Base.metadata.create_all(bind=engine)
    logger.info("DB 초기화 완료")

    # --- [2단계: yield 순간 멈추고 서버가 손님 요청을 열심히 받음] ---
    yield

    # --- [3단계: Ctrl+C 등으로 서버를 끌 때 실행되는 마감 청소] ---
    logger.info(f"[{settings.PROJECT_NAME}] 애플리케이션 종료")


# [1차 주석] FastAPI 본체 애플리케이션 인스턴스를 생성하고 생애주기 관리자를 연결합니다.
# [2차 주석] 우리 챗봇 백엔드 서비스의 메인 두뇌(인스턴스)가 탄생하는 순간입니다.
app = FastAPI(
    title=settings.PROJECT_NAME,
    description="FastAPI 기반 지능형 웹 AI 챗봇 서비스 (Codyssey B7-1)",
    version="1.0.0",
    lifespan=lifespan
)

# [1차 주석] 우리가 만든 [요청 수신] 추적 로깅 미들웨어를 1순위로 등록합니다.
# [2차 주석] 손님이 문을 열고 들어오자마자 가장 먼저 번호표를 뽑아주고 시계를 눌러야 하므로 맨 앞에 세웁니다.
app.add_middleware(LoggingMiddleware)

# [1차 주석] 모든 출처, 모든 헤더, 모든 메소드를 허용하는 관대한 CORS 미들웨어를 등록합니다.
# [2차 주석] 로컬 HTML 파일이나 외부 Cloudflare Tunnel 주소에서 접속해도 브라우저 통신 차단(CORS 에러)이 나지 않도록 고속도로를 활짝 열어줍니다.
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],

# [1차 주석] 서버가 살아있는지 점검하는 헬스체크(Health Check) 엔드포인트입니다.
# [2차 주석] 
#   - 비유: "너 아직 살아있니?" 하고 쿡 찔러보는 생존 확인 벨입니다.
#   - 상세: GET /health 요청을 날려 200 정상 응답과 함께 현재 연결된 DB 이름이 잘 오는지 즉시 확인할 수 있습니다.
@app.get("/health", tags=["Health"])
async def health_check():
    return {
        "status": "healthy",
        "project": settings.PROJECT_NAME,
        "database": settings.DATABASE_URL.split("///")[-1]
    }


# ==============================================================================
# [팀원 라우터 연동 - 오케스트레이션 허브]
# ==============================================================================
# [1차 주석] 세 팀원이 각자 개발한 API 라우터 모듈들을 메인으로 가져옵니다.
# [2차 주석] 
#   - 신재은: 회원가입, 로그인, JWT 토큰 발급 모듈
#   - 조명환: AI 질의응답 및 프록시 스트리밍 모듈
#   - 권태현: 대화 기록 조회 및 최고 관리자 전용 감사 모듈
from app.api.auth_router import router as auth_router  # [신재은]
from app.api.chat_router import router as chat_router  # [조명환]
from app.api.log_router import router as log_router    # [권태현]

# [1차 주석] 🚨 핵심 개념 (VPC 라우팅 테이블 구조): 각 팀원의 라우터를 메인 URL 경로에 결합(Include)합니다.
# [2차 주석]
#   - 비유: 대형 백화점 안내 데스크의 '이정표 표지판'입니다.
#   - 상세:
#     1) 사용자가 "/api/auth/..." 주소로 오면? ➡️ 신재은 팀원의 auth_router로 보냅니다!
#     2) 사용자가 "/api/chat/..." 주소로 오면? ➡️ 조명환 팀원의 chat_router로 보냅니다!
#     3) 사용자가 "/api/logs/..." 주소로 오면? ➡️ 권태현 팀원의 log_router로 보냅니다!
#   - 효과: 세 팀원이 main.py라는 한 파일을 같이 수정하느라 깃(Git) 충돌로 싸울 일이 전혀 없고, 자기 방에서 독립적으로 개발할 수 있습니다.
app.include_router(auth_router, prefix="/api/auth", tags=["Auth"])
app.include_router(chat_router, prefix="/api/chat", tags=["Chat"])
app.include_router(log_router, prefix="/api/logs", tags=["Logs"])
```

## 5. `scripts/run_tunnel.ps1` — Cloudflare Tunnel 배포 자동화

### 💻 핵심 코드 추출 & 1·2차 듀얼 주석
```powershell
# [1차 주석] 스크립트 실행 시 외부에서 포트 번호를 지정할 수 있는 파라미터를 선언합니다. (기본값: 8080)
# [2차 주석] 아무 옵션 없이 실행하면 기본 8080 포트를 쓰고, 필요하면 .\run_tunnel.ps1 -Port 9000 처럼 바꿀 수 있게 한 배려입니다.
param([int]$Port = 8080)

# [1차 주석] 현재 스크립트 위치를 기준으로 프로젝트의 최상위 루트 디렉터리 경로를 계산합니다.
# [2차 주석] 사용자가 터미널의 어느 위치(C:\, 바탕화면 등)에서 스크립트를 실행해도 프로젝트 폴더를 귀신같이 찾아내게 만듭니다.
$ProjectRoot = Split-Path -Parent $PSScriptRoot

# [1차 주석] 가상환경(.venv) 안에 설치된 독립된 파이썬 실행 파일(python.exe)의 경로를 조립합니다.
# [2차 주석] 컴퓨터 전체에 깔린 전역 파이썬과 꼬이지 않고, 우리가 의존성 패키지를 설치해 둔 전용 가상환경을 우선 사용하기 위함입니다.
$VenvPython = Join-Path $ProjectRoot ".venv\Scripts\python.exe"

# [1차 주석] 컴퓨터에 Cloudflare Tunnel 실행 프로그램(cloudflared)이 설치되어 있는지 검사합니다.
# [2차 주석] 평가자의 컴퓨터에 프로그램이 없어서 에러가 나는 참사를 미리 방지하는 검사관 코드입니다.
if (-not (Get-Command cloudflared -ErrorAction SilentlyContinue)) {

    # [1차 주석] 프로젝트 루트 폴더에 다운로드받아둔 파일도 없다면 공식 GitHub에서 즉시 자동 다운로드를 수행합니다.
    # [2차 주석]
    #   - 🚨 핵심 개념 (평가자 중심 Zero-Click 인프라):
    #   - 비유: 게임을 켰을 때 필수 다이렉트X 파일이 없으면 알아서 다운받아 깔아주는 스마트 패처입니다.
    #   - 상세: 평가자에게 "프로그램 깔아오세요"라고 요구하지 않고, 스크립트가 GitHub 최신 릴리즈에서 알아서 다운받아 실행합니다.
    if (-not (Test-Path $CloudflaredLocal)) {
        $DownloadUrl = "https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe"
        Invoke-WebRequest -Uri $DownloadUrl -OutFile $CloudflaredLocal -UseBasicParsing
    }
}

# [1차 주석] FastAPI 백엔드 서버(uvicorn)를 백그라운드 프로세스로 가동합니다.
# [2차 주석] 파이썬 서버를 띄워 0.0.0.0의 지정된 포트(8080)에서 손님 요청을 맞이할 준비를 시킵니다.
$ServerJob = Start-Process -FilePath $VenvPython -ArgumentList "-m uvicorn app.main:app --host 0.0.0.0 --port $Port" -WorkingDirectory $ProjectRoot -PassThru -NoNewWindow

# [1차 주석] Cloudflare 터널을 열어 로컬 서버(127.0.0.1:8080)와 전 세계 인터넷 에지망을 비밀 통로로 직결합니다.
# [2차 주석]
#   - 🚨 핵심 개념 (포트포워딩 없는 0원 보안 배포):
#   - 비유: 우리 집 공유기 문(포트)을 열어 해커에게 노출시키는 위험 없이, Cloudflare라는 거대한 안전 본사와 우리 집 사이에 '지하 비밀 터널'을 뚫는 것입니다.
#   - 상세: 복잡한 공유기 설정 없이도 전 세계 누구나 접속할 수 있는 초고속 무료 HTTPS 공인 URL(`https://xxxx.trycloudflare.com`)이 몇 초 만에 발급됩니다.
```

## 🎙️ 1분 스피치용 핵심 요약 (구술 면접 치트키)

> **"저는 본 프로젝트의 테크 리드이자 백엔드 코어/인프라 담당 안재현입니다."**
> 
> 1. **설정 (`config.py`)**: Pydantic-Settings를 활용해 민감정보를 중앙 집중화하고, **싱글톤 패턴**을 적용하여 파일 I/O 부하 없이 전 모듈에서 단일 설정을 재사용하도록 구현했습니다.
> 2. **데이터베이스 (`database.py`)**: SQLite의 멀티스레드 충돌을 막기 위해 **`check_same_thread=False`**를 적용했고, **`yield get_db()` 제너레이터**를 통해 예외 상황에서도 100% 세션이 종료되도록 하여 **커넥션 풀 고갈을 방지**했습니다.
> 3. **로깅 (`logger.py`)**: 모든 요청에 **8자리 고유 Request-ID**를 부여하고 역방향 프록시 환경의 실제 IP(`X-Forwarded-For`)를 추출하여, 과제 필수 조건인 `[요청 수신]` 및 처리 시간을 트랜잭션별로 완벽히 추적했습니다.
> 4. **통합 및 배포 (`main.py`, `run_tunnel.ps1`)**: FastAPI 최신 표준인 **`lifespan` 컨텍스트 매니저**로 DB 초기화를 자동화하고, 라우터 분할로 팀원 간 충돌 없는 협업을 이끌었으며, **Cloudflare Tunnel 자동화 스크립트**로 포트포워딩 없이 안전한 HTTPS 외부 접속 환경을 구축했습니다.

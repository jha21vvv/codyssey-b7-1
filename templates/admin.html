      요청 로그

      API 요청마다 한 줄씩 저장된 기록입니다 (request_logs). 요청 ID를 누르면 그 요청의 전체 기록을 봅니다.

      시각상태요청응답 시간사용자오류 코드IP요청 ID

      대화 로그

      모든 사용자의 질문과 AI 응답 기록입니다 (chat_logs). 실패한 대화는 실패 종류와 AI 응답 시간을 함께 봅니다.

        요청 추적

        요청 ID 하나로 요청 로그, 대화 로그, 서버 로그(server.log)를 이어서 봅니다.

        요청 ID는 화면의 오류 안내, 오류 응답의 request_id, 응답 헤더 X-Request-ID에 있는 8자리 값입니다.

        요청 ID를 입력하거나, 다른 탭에서 요청 ID를 누르세요.

        요청 로그

        request_logs

        대화 로그

        chat_logs

        서버 로그에서 찾기

        server.log

        서버 로그의 모든 줄은 [요청 ID]로 시작합니다. 서버를 실행한 폴더에서 아래 명령으로 이 요청의 로그만 볼 수 있습니다.
